# Relational Databases (CodeCamp)

Dépôt de suivi du cours **[CodeCamp – Relational Databases v9](https://codecamp.org/learn/relational-databases-v9)**.

Ce repo regroupe mes notes, exercices et scripts SQL réalisés au fil du cours, ainsi que les schémas de bases de données créés en pratique.

## 🎯 Objectifs du cours

- Comprendre les fondamentaux des bases de données relationnelles (tables, lignes, colonnes, clés primaires/étrangères)
- Écrire des requêtes SQL (SELECT, INSERT, UPDATE, DELETE)
- Modéliser des schémas et des relations entre tables (1-1, 1-N, N-N)
- Appliquer les contraintes d'intégrité et la normalisation
- Manipuler une base de données via un SGBD (ex. PostgreSQL / MySQL / SQLite)
